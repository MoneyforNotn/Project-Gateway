McDonnell, Wayne M. *Analysis and Assessment of Gateway Process.* Department of the Army, U.S. Army Intelligence and Security Command, 9 June 1983. CIA Reading Room identifier CIA-RDP96-00788R001700210016-5.

Government-preserved copy:

## Cite modern evidence separately

Do not cite the 1983 memorandum as evidence for a 2026 neuroscience or physics claim.

Use the specific source IDs and bibliographic entries in:

- `research/04_Gateway_Process_Evidence_Review_and_Learning_Guide.md`
- `research/05_Research_Source_Inventory.json`

## Cite this repository

Until the repository has a final GitHub owner/URL, use:

> *Gateway Process — Evidence Review & Source Archive*. Version 0.1.0, 2026.

After publishing, update this file and `CITATION.cff` with:

- repository owner or project authors,
- GitHub URL,
- release/tag,
- DOI if archived through Zenodo or another repository.
