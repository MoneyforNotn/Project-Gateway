# Licensing Notes

This repository contains more than one kind of material, so a single license should not be chosen casually.

## 1. The 1983 U.S. Army memorandum

The original memorandum is a work of the U.S. federal government produced in an official context and is generally not subject to U.S. copyright under 17 U.S.C. § 105.

That does not automatically answer every question about:

- third-party material reproduced inside a government document,
- marks/logos,
- non-U.S. jurisdictions,
- a separately hosted scan's website terms.

This is a project note, not legal advice.

## 2. Supplementary facsimile

The second PDF is retained for source completeness because it contains the printed page missing from the government-preserved copy.

Before public redistribution at scale, review the hosting/source terms for the exact file even though the underlying government memorandum is public-domain material in the United States.

## 3. Project-created transcript and analysis

The editable transcript contains editorial work. The evidence review, README, methodology, glossary, learning materials, and other repository text are project-created material.

**No blanket license has been selected for these materials in this starter package.**

Without a license, normal copyright rules apply.

## Recommended choice

If the goal is to encourage reuse while requiring attribution, a strong default for the project's original text is:

**Creative Commons Attribution 4.0 International (CC BY 4.0).**

If the repository later includes software/code, consider licensing code separately (for example MIT) rather than applying a documentation license to everything.

## Before publishing

1. Decide who owns/authored the project's original material.
2. Choose the license for project-created text.
3. Keep source-material provenance explicit.
4. Do not upload proprietary Monroe/Gateway audio without authorization.
5. Add the selected `LICENSE` file at repository root.
